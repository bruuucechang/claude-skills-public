請幫我查這個台灣政府補助計畫並整理成標準格式：

**輸入：** $ARGUMENTS
（可以是網址、PDF路徑、或計畫名稱關鍵字）

---

## 執行步驟

1. **如果是網址**：用 WebFetch 或 fetch 抓取頁面內容，找到補助計畫的主要說明區塊。
2. **如果是 PDF 路徑**：用 `pdftotext`（PATH 裡找得到就好，不要寫死安裝路徑）擷取文字內容。
3. **如果是關鍵字**：用 WebSearch 搜尋 `site:gov.tw $ARGUMENTS 補助 申請資格 補助額度`，找到官方頁面後再 fetch。

---

## 輸出格式

找到內容後，請嚴格按照以下格式輸出，**每個欄位都必須列出實際內容，不可以只寫「詳見官網」或「請參閱PDF」**：

---

### 📋 計畫基本資料

| 欄位 | 內容 |
|------|------|
| **來源代碼** | （自訂英文縮寫，例如 SBIR、TIIP） |
| **主辦機關** | |
| **大類** | （例如：研發創新、數位轉型、創業育成、節能補助、品牌出口…） |
| **計畫名稱** | |

| **資料來源** | （完整網址） |

（條列式，每個資格獨立一行，例如：

---

## 注意事項

- 所有欄位**必須從原始頁面/PDF 中實際提取**，不可憑空捏造。
- 如果某欄位在來源找不到，請標記 `（原始資料未載明）`。
- 數字金額要清楚（萬元/億元），不要有空格斷字問題（例如「5 00萬」要修正成「500萬」）。
- 中文條列項目（一、二、三 或 （一）（二））請各自換行，不要擠在同一行。
- 輸出完畢後，請問使用者：「要加入 scraper.py 嗎？」
