# claude-skills-public

我自己用的 Claude Code skills、全域規則（AGENTS.md）、hooks 與小工具的公開快照。

- 這是從私人 repo 過濾後自動匯出的，**沒有 git 歷史**，也不收 PR。
- 記憶檔、帳號設定、本機排程與 settings.json 都不在這裡；規則裡的 `[[名字]]` 指向的記憶檔因此會找不到。
- email、主機名、IP 已遮掉，所以有些 hook（例如 git 作者檢查）照抄會不能用，要改成你自己的值。
- 外來的 skill 不在 repo 裡，清單在 `install-external.sh`；`tufte-viz` 是 MIT 授權的第三方 skill，出處見它的 `ORIGIN.md`。
